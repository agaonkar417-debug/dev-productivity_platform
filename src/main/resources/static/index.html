        Template syntax
        
      Write {{name}} wherever a value should go. Every distinct name becomes a form field.
          Add filters to change the naming style. They apply left to right:
      
        
      
          
      {{entity}}as typed: order item
      
          
      {{entity|pascal}}OrderItem
      
          
      {{entity|camel}}orderItem
      
          
      {{entity|kebab}}order-item
      
          
      {{entity|snake}}order_item
      
          
      {{entity|constant}}ORDER_ITEM
      
          
      {{entity|title}}Order Item
      
          
      {{entity|plural|snake}}order_items
      
          
      {{pkg|path}}com.acme → com/acme
      
          
      {{today}}, {{year}}built in, no field needed
      
        
      
        
      Paths can use placeholders too, e.g. src/{{entity|kebab}}/index.ts.
